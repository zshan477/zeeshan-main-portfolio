# Zeeshan Jamil Portfolio

WordPress export of Zeeshan Jamil’s local portfolio site (theme: `zeeshan-jamil`).

This repository is a file export, not a live Vercel site. Cloning it will not produce a running website by itself.

## Setup

1. Copy `wp-config-sample.php` to `wp-config.php`.
2. Fill in your database credentials and WordPress salts in `wp-config.php`.
3. Import a MySQL dump of the original site.

Posts, pages, and other content live in MySQL. A clone needs a database import to show that content.
